**https://nowornever-Ian.github.io/beyond-game/**

## 如何開啟 GitHub Pages（只需做一次，約 1 分鐘）

1. 用手機或電腦打開：https://github.com/nowornever-Ian/beyond-game
2. 點上方 **Settings**（設定）
3. 左側選 **Pages**
4. **Source** 選 **Deploy from a branch**
5. Branch 選 **main**，資料夾選 **/ (root)**
6. 點 **Save**
7. 等約 1～2 分鐘後，用上面的網址就能玩

## 注意

目前倉庫裡的 `index.html` 若還是不完整版本，請把完整遊戲檔案（Beyond.html）重新命名成 `index.html` 後，上傳覆蓋到這個倉庫的根目錄。

完成上述步驟後，網址就會永久有效，不會再過期。
